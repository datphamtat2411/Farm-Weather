# Task 07 — station Flash ring and logical Class A
Ch.4 §4.1, §4.3.2 and §4.4.2; Ch.6 D05.

- 64 KiB, 4 KiB two-page sequence journal, 960 slots of 64 bytes, 2 KiB erase pages. Record header is sequence + CRC32, 48-byte body is FPort, length and exact Protobuf tail (first canonical sequence field restored losslessly), independent 8-byte ACK marker. Body programmed before commit header; never overwrite a pending slot. Sequence is durably reserved before record construction; gaps are explicit, no reuse after reboot. Reclaim only pages with no pending records. Reserve 32 slots for events (periodic maximum 928); 960 total if events fill the reserve. Reject rather than silently overwrite; BUFFER_GAP records the affected sequence. Near-full hysteresis 80%/70%. Page fragmentation can reduce usable capacity, not an unconditional three-day guarantee.
- Wokwi uses an external custom 64 KiB NOR model on I2C because Blue Pill target cannot dedicate its entire on-chip Flash to the queue. This is an adapter, not a physical BOM change. Memory survives MCU reset within the same simulator process, not a fresh simulation. Native tests enforce page erase and 1-to-0 programming and inject torn writes. STM32L476 flash integration/linker partition is not deployable in the compile probe. Real ECC, wear, erase duration and power-loss behavior require hardware validation. If an ACK marker is partially programmed recovery fails closed rather than treating it as delivered. CRC detects corrupted committed records, does not repair them.
- Class A logical RX1/RX2 one and two seconds after uplink, application ACK FPort 20 explicit non-cumulative list (maximum eight), only records sent in current session can be released. Retry bounded to 5–60 logical seconds plus window, normal recovery pacing 5 seconds; alternate event/periodic and oldest/newest. FPort payload cap configurable (default 51 bytes), oversize held. New simulated frame counter per send; not a real LoRaWAN session/OTAA, AES, ADR, MIC, RF airtime or regional compliance implementation.
- Serial control commands: LINK DOWN/UP, ACK DROP/AUTO/MANUAL, LIMIT n, DOWNLINK <port> <hex>. RADIO_TX contains actual bytes, FPort, sequence, frame counter and delivery flag. Default mock gateway ACKs in RX1 only after simulated reception; this does NOT claim SQLite durability. Task 08 replaces mock ACK with external Edge commit ACK via manual mode. Local sensing/actuation independent of radio.
- Native ring_test.cpp runs in development CI with UBSan, includes full capacity, page reuse, journal rollover, CRC, ACK loss, out-of-order ACK, payload limit and interrupted writes. D05 link-recovery scenario mandatory at Task 17 under existing quota policy; no remote simulator run on ordinary push. Serial verifier compares exact encoded bytes across retries and observes local output. No physical RF or flash validation claim.
