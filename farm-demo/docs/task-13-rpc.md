# Task 13 — Remote control and configuration

Cloud authorization remains in FarmApi (Task 12). Gateway subscribes to native ThingsBoard Gateway RPC; commands are admitted into SQLite with original UUID, creation/expiry and method. The Gateway checks expiry before each retry and sends Protobuf FPort 21 only after a valid uplink. The serial bridge schedules command in RX1 and weather ACK in RX2. With no command it preserves the existing ACK behavior. Wokwi's artificial UTC epoch requires translating remaining TTL at dispatch. This is not an RF measurement or production ChirpStack queue integration.

Firmware independently validates the canonical Protobuf, UTC expiry, config version and safe wind state. Valid configuration takes effect for the next aggregation boundary, battery protection still overrides configured period. Remote stop is latched and released only by local inspection button under safe conditions. Buzzer test is bounded to three logical seconds, never suppresses wind alarm. No start pump command exists. A separate 4 KiB simulated NOR configuration journal survives reset and fails closed if torn/full (85 admissions/local confirmations, no silent eviction; fresh demo requires new simulator image after exhaustion). A durable admission prevents repeating a side effect after reset; a crash before result may yield UNKNOWN. FPort 22 responses use the existing weather ring/ACK mechanics and independent sequence/CRC. Gateway accepts results only for dispatched commands on the mapped station. Cloud gets a dedicated command_<uuid-without-hyphens> string containing lifecycle, revision and confirmed snapshot. Readback is required before reporting publication complete. APPLIED means a device result, not native RPC delivery. Desired shared and applied client attributes are independent.

Run existing Edge gateway, serial bridge, and sync_service processes with the Task 12 scoped credentials. The sync service subscribes to v1/gateway/rpc, and its callback stores commands in the same SQLite file used by gateway.py. Use FarmApi POST /api/farm/stations/{station UUID}/rpc. Dashboard is Task 14. Hardware acceptance remains deferred under the repository CI policy; development evidence is native tests and actual Cloud/MQTT integration, not measured GPIO/RF.
