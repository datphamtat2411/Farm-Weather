# Task 08 — Edge Gateway
Ch.4 §4.3, §4.4.2; Ch.5 §5.2.2. Scope: local ingestion, not Cloud sync.

- Python service subscribes to ChirpStack-shaped application/<id>/device/+/event/up (MQTT QoS 1), maps configured application/DevEUI to station, validates FPort, Protobuf, measurement clock and metadata. Original measurement timestamp is never replaced by reception time. Invalid quality fields are omitted. Event rainfall window never becomes periodic rain.
- SQLite uses WAL, synchronous FULL, explicit writer transaction, compound identity, SHA-256 normalized payload, priority and retry columns, receiver metadata, bounded quarantine. Exact replay gets the same explicit ACK, different content is quarantined without modifying original. Invalid input receives no ACK. Failed commit/capacity causes service failure and no application ACK. IN_FLIGHT resets on startup; actual Cloud sending, verification, synced retention/compaction and reconnect/backoff are Task 09. 64 MiB soft disk budget includes WAL/index pages; refuse periodic writes at 95% of that budget to reserve event headroom. No eviction of pending rows; budget is not a hard filesystem quota. Diagnostic near-full hysteresis 80/70%.
- Legacy diagnostic smoke importer remains for prior acceptance only, never generates ACK. Old schema is migrated preserving rows as QUARANTINE because diagnostics cannot be assumed equivalent to validated wire data.
- SerialBridge translates delivered RADIO_TX bytes (not diagnostic JSON) to MQTT event, uses logical reception time and clock trust, requires ACK MANUAL; forwards only matching ACK during RX1/RX2. A simulator host must connect the line input and command output. Real LoRaWAN/OTAA, RF metrics and Wokwi interactive transport verification remain outside development acceptance.
- Local run (Linux/cloud runner): pip install -r farm-demo/edge/requirements.txt; python -m grpc_tools.protoc -I farm-demo/protocol --python_out=farm-demo/edge farm-demo/protocol/weather.proto. Run Mosquitto on private loopback, then python farm-demo/edge/gateway.py --mapping farm-demo/edge/devices.example.json --db weather.sqlite. Example broker config is loopback-only, anonymous for demo; production ACL/credentials/TLS are Task 12. Use EDGE_MQTT_USERNAME/PASSWORD for configured local credentials. Service uses stable client ID and persistent QoS session, supervisor should restart after failure. MQTT ACK enqueue is not delivery guarantee; station retries if downlink is lost.
- Development CI must pass; hardware quota policy unchanged. No real Cloud sync or physical RF claim.
