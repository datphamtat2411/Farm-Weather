# Task 15 — Lịch sử, thống kê và báo cáo thời tiết

Native FarmWeather dashboard has Tổng quan and Lịch sử & thống kê tabs. Choose 24h, 7d, 30d or custom local time (UTC+7; max 31 days), then Xem thống kê. Hourly buckets for up to 24h, local-day buckets otherwise. Raw record table paginates 50 rows. Refresh the query to include new backfill. Export CSV is a separate audited request and uses the same scoped human JWT; viewers can read history but cannot export through the business endpoint. No direct PostgreSQL queries or service credentials in browser.

- Periodic identity and original UTC timestamp join the native per-key points; event fields are excluded. Exact repeated points are idempotent; conflicting identity/timestamps fail explicitly.
- Range convention: (start, end] for timestamp, with full period [end-period_s, end] needed for aggregation. No prorating rain, no overlap double-counting, no missing-as-zero. Partial periods remain visible as raw records; bucket totals may differ from range total when a period crosses a bucket boundary.
- Validity mask applied per group. Temperature, humidity and pressure use valid sample means; wind speed weighted by period duration; gust maximum; direction vector weighted by duration with resultant threshold 0.2; rain sum in mm; pin minimum and last. Coverage is actual interval duration, not point count. Gold points indicate partial coverage, gaps are not connected. Alarm count counts native alarms starting in range.
- CSV includes UTC milliseconds, local ISO timestamp, record ID, period, quality mask and values; invalid cells blank, valid zero retained. Raw data is exported, not interpolated statistics.
- Native tests cover mixed periods, backfill, duplicate points, boundary crossing, missing and invalid data. The real ThingsBoard/Chromium integration publishes historical packets and checks viewer denial, operator download, data readback and responsive rendering. Evidence: history-report.json, weather-history.csv, history-viewer.png, history-operator.png in security-evidence. No claim of physical measurements or public hosting.
