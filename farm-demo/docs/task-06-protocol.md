# Task 06 — WeatherRecord v1
Reference: Chapter 4 section 4.2, Table 4.2; Chapter 5 table 5.4.

- Single schema: protocol/weather.proto, proto2 presence for legitimate zero vs missing values. FPort 10 uses exactly the thirteen report field numbers. FPort 11 is an explicitly defined event snapshot schema with shared sequence namespace, status changes, output state, optional triggering measurements; no periodic rainfall field. Ports 20/21 are reserved for Task 07/13.
- Firmware: bounded allocation-free encoder for these two fixed varint-only messages, ZigZag signed temperature; checks metadata, measurement domains, and capacity. Values quantized once to tenths (nearest, ties away from zero), rain is integer tips, battery millivolts. Raw serial diagnostics retain their existing precision for Tasks 02–05; fport and wire_hex carry the actual bytes. Hex is simulator framing only, not LoRaWAN overhead.
- Gateway: official protoc-generated Python decoder; validate type, size, required fields, presence/valid_mask, domains and supported FPort; no fresh zero for invalid measurements. Device identity supplied by trusted DevEUI mapping (Task 08), original UTC seconds become milliseconds. Reject invalid timestamp zero; RTC trust/quarantine belongs to Tasks 07–08.
- Native test emits binary vectors and official Python decoder checks exact report values, negative temperature, valid zero, missing measurements, boundaries, event transitions, and malformed payload negative controls. All 128 validity-mask combinations are verified against independent protoc encoding and decoded field presence. The report vector is also encoded independently by protoc-generated Python code and compared byte-for-byte. CI publishes protocol-report.json with measured application payload sizes, hex, and decoded values. No RF or physical measurement.
- The STM32L476RG compile probe also links the shared codec; it remains non-deployable.
- Hardware acceptance automatically validates every actual serial wire payload against diagnostics without removing previous scenario verifiers. Remains deferred until Task 17 under existing quota policy.
- Generate bindings from repository root: python -m pip install -r farm-demo/protocol/requirements.txt ; python -m grpc_tools.protoc -I farm-demo/protocol --python_out=farm-demo/edge farm-demo/protocol/weather.proto. Generated file is ignored. Development and hardware workflows generate it before tests.
- 64-byte encoder buffer is not a guarantee that every payload fits a LoRaWAN data rate or a 64-byte Flash slot including metadata. Task 07 must check both actual limits, handle oversize explicitly, preserve bytes and sequence across retries, and implement durable counters/ACK. No radio, queue, Cloud, or outbox migration in Task 06.
